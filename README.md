# Photoroom-inspired commerce AI site

A production-oriented Next.js 15 App Router recreation inspired by the public information architecture and visual language of the current Photoroom marketing experience.

## Stack

- Next.js 15 / App Router
- React 19
- TypeScript strict
- Tailwind CSS v4
- Framer Motion
- Lucide icons
- Vercel-ready configuration

## Routes

- `/`
- `/solutions`
- `/enterprise`
- `/about`
- `/tools/background-remover`
- `/tools/batch-edit`
- `/tools/ai-product-photography`
- `/tools/product-staging`
- `/tools/brand-kit`

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run start
```

The implementation uses independently authored components and styling rather than proprietary source code or private assets.
